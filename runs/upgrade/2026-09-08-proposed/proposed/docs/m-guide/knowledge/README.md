# Knowledge index

Trang kiến thức theo khía cạnh. Mục lục máy: [../catalog.yml](../catalog.yml).

| Thư mục | Vai trò |
|---------|---------|
| lyrics/ | Viết lời, prosody, rhyme, hook/pre/bridge |
| melody/ | Contour, phrase, cadence, motif |
| harmony/ | Hòa âm, chức năng, voicing, mode/ngũ cung |
| rhythm-form/ | Form, tempo, groove, syncopation, patterns |
| vocal/ | Bè hát, breath, melisma, techniques |
| vietnamese/ | Thanh điệu, vần/thể thơ, ưu tiên xung đột |
| arrangement/ | Phối khí, energy, dynamics, drum/bass, intro–outro |
| musicxml/ | Rules, anti-patterns, structure, lyric XML/encoding, performance markings, checklist |
| styles/ | Thẻ phong cách (khái quát) |
