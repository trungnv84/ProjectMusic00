## Observed problem relevant to Package 3

Previous review found that v4 repeated nearly the same hook / pitch-rhythm cell across Chorus, Chorus 2 and Final Chorus, while Verse phrases also reused nearby cells with similar quarter/eighth density and simple stepwise contours. The existing knowledge already covers catchiness, contour, phrase structure and motif development, but rhythmic identity is still mixed into catchiness rather than having its own treatment, and hook taxonomy is missing.

## Diagnosis

1. `catchiness.md` already contains a useful rhythmic-hook idea, so Package 3 must deepen and separate it rather than duplicate it.
2. `contour.md` and `phrase-structure.md` already own melodic contrast; a new `melodic-contrast.md` would create a second source of truth. Package 3 therefore expands those pages in place.
3. A song may be memorable through a rhythmic, lyrical, vocal, harmonic, production or call-response hook; treating every hook as a melodic hook would over-constrain composition.

## Package 3 target

Add durable knowledge that lets the composer choose and realize different kinds of melodic/rhythmic identity without turning every song into the same catchy formula.
